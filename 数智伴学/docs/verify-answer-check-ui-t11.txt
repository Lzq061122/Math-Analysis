**怎么复现（任何人可以照做，不依赖历史文件）**：

1. 跑 `C:\Python314\python.exe tests\verify_answer_check_ui.py`；
2. 从 `docs/verify-answer-check-ui.txt` 里取所有形如 `PASS|FAIL|未验证 <id>` 的 id（当前 175 条）；

   `13.11.8b`（R-06 `all_checked` 主按钮）——剩下的就是 T11 冻结版的 172 条；
4. 与本文件末尾的清单逐条比对，应当完全一致（0 删除、0 改名）。

**新增与旧 id 的关系（按时间顺序）**：T11 冻结时 172 条 → t16 追加
`13.1.10b`（N-02：数字要渲染出来）与 `13.11.8b`（R-06：`all_checked` 主按钮），共 174 条 →
t18 把 `13.1.10b` 的断言体从「查 hero 整块文本」加强为「按 `.kv` 逐格取 k/v + 与 state-flag 同值」，
并追加 `13.1.10b-mut`（变异自证），共 175 条。
因此相对 T11 冻结版，新增就是这 3 条：`13.1.10b`、`13.1.10b-mut`、`13.11.8b`；
本清单采用「当前 175 条去掉这 3 条」的口径，得到 172 条。
