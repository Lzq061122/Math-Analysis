### 跑起来

```bat
cd 数智伴学
python src\launcher.py
```

桌面端需要 Python + `pip install pyside6 pillow`，细节见 `数智伴学/README.md`。
本机实测环境为 Python 3.14.7；网页端与测试只用标准库，桌面端另需 PySide6。

### 跑验收

```bat
python tests\verify_answer_check_150.py
python tests\verify_answer_check_ui.py
```

- 第一条：源码级验收，137 条断言，退出码 0 为通过。
- 第二条：浏览器端到端验收，175 条断言，会自起服务在 `127.0.0.1:8899` 并驱动 Edge。
