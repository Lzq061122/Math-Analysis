### 1.3 18 项指标落点（key 与契约逐字一致）

| key | 实现口径（简述） |
|---|---|
| `class_students` | 在册学生数；**学生筛选会变、知识点/错因筛选不变**（D7） |
| `expected_students` | `expected_student_keys(config)` 人数；未配置 → 暂无 |
| `submitted_students` | `r2_contract.submitted_student_keys(records)`（只数非缺测；S9 全缺测 → 9） |
| `valid_answers` / `insufficient_answers` / `missing_answers` | 记录级 `answer_state`，缺测优先于内容量 |
| `unsubmitted_answers` | `roster_status()` 的未提交格子（未配置 → 暂无） |
| `unverified_answers` | 有效作答中 `verified=False` 的份数 |
| `confirmed_mistakes` | 当前版本 `first_bad` **且** `cause_state='decided'`（`missing_steps` 不计） |
| `knowledge_error_freq` | 按知识点分别计、同题同类去重；未分类单列不计入已知类别 |
| `affected_students` | 至少一条已确认错题的去重学生数（分母=班级人数） |
| `cause_freq` / `undecided_causes` | 按 `cause_code` 分组；待判断 = first_bad 且 undecided |
| `question_score_rate` | 该题确认得分之和 ÷（份数×满分），同时给 `scored_count`、`rate_percent` |
| `assignment_total_score` | **逐生**有效确认得分之和（`student_total_scores`）；不完整→None；卡片写「完整成绩学生 6 / 应参与评分 10」，不显示满分合计 |
| `average_score` | 完整成绩总分平均（一分的部分评分都不掺） |
| `score_coverage` | 完整成绩数 ÷ **应参与评分学生数**（`scoring_students`），无应评分题 → 无法计算 |
| `repeated_errors` | `knowledge_pairs` + `cause_pairs` 两类分列，卡片总数=两者之和 |
| `class_common_issues` / `student_priority_issues` | 前者**按涉及学生数**主排（频次辅助）；后者复用 `app/tutor.py` 的 3/2/1 近期加权，`today` 必须由调用方给出 |

### 1.4 筛选与 R1 遗留关闭

- **批次**（C1）：`list_batches()` 含历史未配置批次；看板批次下拉可选，`batch=""` = 全部批次（不跨批次相加）。
- **日期**（D6 三级）：批次 `occurred_on` → 回退该批次 `answers.occurred_on` 非空最小值 → 都没有则标「无业务日期」，日期筛选生效时不计入并在 `notes` 写明「n 个批次缺少业务日期，未计入日期筛选」。
- **学生**：只收窄明细与学生级指标；班级人数/应作答人数随之变化，作业总分/平均分/覆盖率默认全班口径，`group_scores=True` 才切「群体成绩」视图（`notes` 注明范围）。
- **知识点/错因**：只影响错题分布、涉及学生与明细；成绩类指标不变。
- **演示隔离**（C2）：只在唯一入口 `_formal_rows()` 里用 `include_in_formal_stats(source, batch_is_synthetic)` 过滤；纯演示批次整批「暂无」+ `demo_batch=True`；白名单外任何函数不得再判 `source`/`synthetic`（AST 断言 3.20/3.20b）。
- **同口径**（C6）：四维状态与当前版本判定全部来自 `grading.effective_rows()` / `grading.current_checks()`；统计与详情共用同一判据（断言 1.40）。
- **不算正确率/掌握率**：返回值里没有任何 accuracy/mastery/趋势字段（断言 1.39）。
