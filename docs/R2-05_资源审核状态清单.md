# R2-05 首批教学资源审核状态清单（1.9.0）

**口径（硬）**：本清单里每一条资源都是 `status=pending_review`（待审核），数学正确性与教学适切性两项审核**都还没有签署**。按 `docs/R2_接口契约.md` §5 第 8 条与派单 B 条，未审资源**不得进入正式推荐**；因此代码侧正式推荐（`match_resources`）里看不到这批资源，只有双审核通过并发布之后才会出现。

**生成方式**：`resources/teaching_resources/*.json` → `tools/import_resources.py`（导入即送审）→ 本清单逐条登记。清单里的「资源 key」是跨版本稳定 ID，版本号与审核记录在 `teaching_resource_versions` / `teaching_resource_reviews` 两张表里可追溯。

**人工审核怎么走**：打开「教学资源与辅导 → 审核发布」，选一条待审核资源，先由一位老师签「数学正确性」，再由**另一位**老师签「教学适切性」，最后点「发布这一版」。同一账号两项都签会被拒绝（自审自发不算双审核）。
