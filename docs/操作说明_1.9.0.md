# 数智伴学 1.9.0 操作说明（R2 五项功能）

本文件面向使用软件的老师与负责维护的技术同事。1.9.0 在 1.8.1 与 R1 合并版之上增量开发，
原有功能一处未删、界面一处未改，新增的五项能力都挂在**现有页面**上，不改变老师的既有操作习惯。

---

## 一、升级须知（三步）

| 步骤 | 做什么 | 为什么 |
|---|---|---|
| 1 | 先备份：软件内「备份」导出一份 zip，或直接复制整个数据目录 | 升级会做结构迁移。迁移前软件会自动在数据目录旁留 `app.db.bak-<时间>-<随机>`，但自己有备份更稳 |
| 2 | 用 `数智伴学-1.9.0.zip` 解压后替换旧目录，不要把新文件覆盖进旧目录再运行 | 目录里带 `_internal`，混放会加载到旧依赖 |
| 3 | 首次启动后看一眼「作答核对」与「学情看板」两个页面能正常打开 | 这一眼等于确认迁移成功（旧库的作答、错题、追问原话都应还在） |

旧库升级是**就地增量**：只建新表、补新列，不删列、不改既有行的语义，
`SCHEMA_VERSION` 保持 `4` 不变（升版会让 1.8.1 的库被判定为结构不兼容而打不开）。

## 二、五项新功能在哪里、怎么用

### 1. 压缩包批量导入（R2-01）

**入口**：班级 → 学生名单 → 「导入作答」页 → 右上「导入作答压缩包…」

- 压缩包结构固定：根目录放 `answers.csv`，图片放 `images/` 下；CSV 表头与原来的 CSV 导入一致，
  只多一列「图片路径」（包内相对路径，多张图用 `;` 分隔）。
- 点「选择压缩包」后先出**预览**，六类分开列：有效 / 重复 / 冲突 / 缺测 / 未匹配学生 / 文件异常。
  预览不写任何正式数据，可以反复换包。
- 相同记录（记录编号 + 内容一致）自动跳过；**编号相同但内容不同**会标成冲突，由老师逐条选「跳过」或「覆盖」。
  覆盖会让这条作答之前的核验、错因与评分失效（这是有意的，见第四节）。
- 只有照片没文字的记录会存成「内容不足」，等老师补录；本轮不做手写识别。
- 限制：压缩包 ≤100 MB、解压后 ≤300 MB、文件 ≤2000 个、单图 ≤10 MB，只收 JPG/JPEG/PNG。
  加密包、嵌套压缩包、绝对路径、越界路径、不支持类型一律整包拒绝，且**不落盘**。
- 模板：页面右侧「下载压缩包模板」。

### 2. 批量核验与教师评分（R2-02）

**入口**：班级列表 → 「批量核验与评分」；或「作答核对」页内进入单条核对

- 批量核验可以选范围：本批次全部待核验 / 本批次全部记录 / 只跑指定几条。跑的过程中有进度与逐条状态，
  可以「取消未处理」，可以「重试失败」，单条失败不影响其他条。
- **重复核验不会覆盖你已经做过的判断**：已确认的错因、已确认的成绩、人工核验过的结论都受保护。
- 单条视图分三块：①题目与标准解法 + 本题评分标准与该题版本 ②学生原始步骤与关联图片（多图可逐张看）
  ③核验结果 / 首个能确定的错误步骤及原文 / 候选错因与你的判断 / 知识点 / 评分。
- 评分：0 到该题满分，最多两位小数。可以只填「建议分」，正式分必须由你明确确认后生效。
  用步骤分时把扣分项、扣分值、说明填进去，系统会校验「满分 − 扣分合计 = 得分」。
  改已确认的分要写理由，会记录修改人与时间。
- 评分标准是**按题**的：改第 3 题的标准只会让第 3 题的旧成绩失效，第 1、2、4、5 题的成绩不受影响。

### 3. 班级与个人学情看板（R2-03）

**入口**：班级列表 →「学情看板」；或「班级学情」/「学生个人学情」页内「数据看板」

- 18 项指标 + 两项排序结论（班级共性问题、个人重点问题）。指标卡下方是图表：
  知识点错误频次（横向柱状）、错因分布（条形）、各题错误情况、学生×知识点热力图、
  完整成绩分布、各题得分率，以及可筛选的明细表。
- 交互：点知识点 → 只看该知识点的学生与错题；点热力图格子 → 该生该知识点的错题；
  点学生 → 进入个人看板；双击错题 → 看原始作答、教师判断与证据；可随时清除筛选。
- **筛选不会改变班级总量指标**：知识点/错因筛选只影响错题分布与明细，班级人数、完整作业总分、
  班级平均分、评分覆盖率始终按全班算（要看某个群体的成绩，界面会单独注明范围）。
- 缺测、未提交、内容不足、无法核验、未评分**一律不计为错误或零分**。
- 批次可自选，包含历史批次；同名不同批次各自独立统计。

### 4. 学情报告 PDF 导出（R2-04）

**入口**：班级学情页 / 个人学情页 → 「导出报告」

- 先出预览，再决定导出。**预览与导出用的是同一份数据快照**：预览之后即使别人改了数据，
  导出的 PDF 仍是你预览时看到的那份；要新数据就点「刷新预览」再导出。
- 报告含：统计范围与生成时间、作答及审核概况、成绩统计、知识点/错因分布、共性问题、代表性错题、
  已保存的教学建议；个人报告另含重点辅导问题、已安排练习。
- 代表性错题默认按高频选取，每类最多 2 条、总数不超过 6 条，可以自己勾选。
- 班级报告默认不出现能直接认出学生的信息（姓名/学号），个人报告只含该生本人。
- 导出时填「用途」，会记入导出历史（账号、时间、用途、类型、筛选范围、文件校验值）。
- 统一 A4 纵向；长表格会跨页并重复表头，公式与中文不会乱码或被截断。

### 5. 教学建议、分层提示与举一反三（R2-05）

**入口**：班级列表 → 「教学建议与练习」；也可从个人学情、错题详情、班级共性问题进入

- 资源按「单元 + 知识点 + 已确认错因」匹配，顺序是：精确匹配 → 单元知识点通用 → 没有匹配就提示人工补充。
  **错因没确认时只推通用资源**，不会替你猜错因。
- 三级提示：P1 指出要重新检查的关键步骤 → P2 提示相关数学性质/规则 → P3 给局部示例。
  默认按 P1→P2→P3 给，你可以调整。系统会记录学生是否先独立尝试、实际用了哪一级、有没有改对。
  **完整解析必须在学生独立尝试之后才提供**；老师提前看答案不算学生完成。
- 举一反三练习分三类：概念澄清、步骤巩固、迁移应用。每道题给出推荐理由、知识点、难度、答案与解析，
  可选择、调整并保存开发成辅导任务（个人或班级）。
- 辅导任务有状态：草稿 / 已安排 / 已完成 / 已取消，可改、可查历史、可手动记录完成情况。
- 纸笔练习可导出两种 PDF：**学生版**（只有题目与作答空间）与**教师版**（题目 + 答案 + 解析 + 教学提示）。
- **资源要经过两道审核才能用于正式推荐**（数学正确性 + 教学适切性，两位老师分别签）。
  首批资源目前状态是「待审核」，人工审核完成前不会出现在正式推荐里——这不是故障。

## 三、数据边界（两条硬规则）

1. **演示数据与正式数据分开**：合成演示批次在界面上有标记，正式统计、报告与教学推荐一律排除它。
   演示模式可以随便试，不会污染班级数字。
2. **真实学生个体数据不外发**：作答分析、批改、辅导建议、追问、错因更新都不向生成式模型发送真实学生数据，
   这条限制在后端实施，界面上的「允许个体诊断使用我配置的 AI 通道」开关也覆盖不了它。
   真实数据走本地规则、已审资源或人工处理。

## 四、改一条数据会发生什么（失效规则）

| 你做的事 | 系统怎么处理 |
|---|---|
| 改作答内容 | 这条作答的旧核验、旧错因判断、旧评分一律失效，需要重新核验与评分 |
| 改教师错因判断 | 关联错题与统计随之更新 |
| 撤回错因判断 | 退出错因统计，但**核验结果与成绩仍然有效** |
| 改评分 | 成绩统计更新 |
| 撤回评分 | 回到「未评分」，历史留痕不删 |
| 改评分标准（某题） | 只让**该题**的旧成绩失效，其他题不受影响 |
| 改应作答范围 | 重新计算完整成绩与评分覆盖率 |
| 学情依据变化 | 关联的辅导建议标记「需复核」 |
| 资源更新版本 | 新任务用新审核版本，历史任务保留原版本可追溯 |

## 五、常见问题

**Q：导入压缩包提示「文件异常」怎么办？**
页面上会逐条说明原因（类型不支持/超过单图上限/路径越界/图片缺失…）。图片缺失可以选「跳过图片继续导入」，
文字作答照常进来；其它异常按提示改包后重新预览即可，预览阶段不写任何数据。

**Q：覆盖率显示 60%，可我们班交齐了？**
覆盖率 = 完整有效成绩人数 ÷ 应参与评分人数。只有**全部应评分题都确认了成绩**的学生才算「完整」。
部分评分的学生不计入平均分，也不计入分子。分母含应作答但完全没交的学生。

**Q：批改时提示「本标准版本已变」？**
同一题的标准被改过（版本号变了）。到单条视图的「本题标准与该题版本」里确认后重新评分即可。

**Q：为什么撤回错因后，成绩还在？**
这是有意的：错因判断、核验、评分是三个独立维度。撤回错因只让这条退出错因统计，
它作为「这道题做得对不对、给了几分」的记录仍然有效。

**Q：报告里的数字和看板对不上？**
先看两边的「统计范围」是否一致（批次、日期、学生/知识点筛选）。看板筛选知识点时班级总量指标不变，
而报告如果按筛选后的群体出，会在报告里单独注明范围。
