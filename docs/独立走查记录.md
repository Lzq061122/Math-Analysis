## 4. 下一轮要改的 3 件事（按影响排序）

**第 1 件｜给合成演示数据一个界面入口，并把空状态的下一步说清（对应发现 ①③）**
在作答核对总览（或其他入口）加「载入合成演示数据 / 重置合成数据」两个动作，旁边写「只影响合成数据，真实导入的作答不受影响」，成功后原地刷新，并在按钮旁显示 `seeded.answers` 与 `kept.imported_answers` 两个数字。空状态时把「还没有作答」那一段改成一条明确指令（例如「还没有作答：导入本班作答，或先用合成演示数据看看」），并把「导入作答」升成可见按钮。**不改这一条，A7 的「演示无需现场选文件」在界面上落不了地。**

**第 2 件｜把「待核对」这个词拆成两个说法（对应发现 ②⑧）**
班级卡片的数字改成「待确认错题 / 已确认错题」，作答核对页保留「待核对作答」；总览空状态删掉「当前作业：未命名批次」，三句同义文案收成一句。这一条不改，老师在这里建立的认知会在下一步被打碎。

**第 3 件｜把提交与「下一步」各自唯一化（对应发现 ④⑥⑤）**
主按钮保持「保存错步，原因待判断」唯一实心；「采纳选中原因并保存」改成选中候选后才出现的显式次级动作（或收进候选区里，跟着那条候选走），不要让两个提交按钮并排在底部栏。回执页把「查看下一份」放进首屏（或进底部固定栏）。顺手把遗留 toast 在跳页时清掉。

**低成本顺带修**：保存时间本地化（发现 ⑨）、记录表加「作业批次」列（发现 ⑩）、「打开」改成按钮（发现 ⑪）、「首处不等价」只保留行内那一处（发现 ⑫）、`docs/模拟数据清单.md` 注明 seed 会复用班级现有学生、界面姓名以实际学生为准（发现 ⑬）。
