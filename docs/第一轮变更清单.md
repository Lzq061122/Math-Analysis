# 第一轮变更清单（作答核对 A1–A7）

> 本轮把「学生作答 → 错步定位 → 教师判断错因 → 回执 / 队列 / 记录」做成可演示、可回归的功能。
> 工作区内共 50 个文件发生变更：**49 个由本轮开发产生**、1 个是输入的任务清单本身（`数智伴学_修改任务清单.md`，13:21 落盘，不计入产出）。
> 本文只描述"改了什么"，验收结论见 `docs/第一轮交付说明.md`，证据见 `docs/验收证据_第一轮_复验.md`。
