变异体做法：把 `src/` 整棵树拷到临时目录 → 按预期改错一处 → 用**子进程**跑同一批关键断言。

```

PASS T7-M.统计过滤 摘掉「demo_source = check_state.DEMO_SOURCE」后同一批断言确实变红（断言不恒真）
PASS T7-M.依据闸门 变异锚点在 answer_check.py 里恰好出现 1 次（改一处只影响一处）
PASS T7-M.依据闸门 摘掉「if not basis:」后同一批断言确实变红（断言不恒真）
```

变异体输出原文（子进程 stdio 落盘后读回）：

```

MUTANT_RED 至少一条变红：basis_still_ok=False stats_still_ok=False
```
