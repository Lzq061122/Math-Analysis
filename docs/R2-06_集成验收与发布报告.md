## 二、全链路验收（派单 §9.1）

用 `tests/fixtures/R2_验收_10x5.zip` 作为标准输入，桌面端按下列顺序一次走完，全部由
`tests/verify_r2_06_e2e.py`（31 项，exit 0）自动执行并断言：

```
班级与学生管理 → ZIP 导入 → 确认应作答范围 → 批量核验 → 教师确认错因与成绩
→ 班级学情 → 个人学情与证据追溯 → 教学建议/分层提示/练习推荐 → 纸笔任务 → 班级与个人 PDF 报告
```

关键结果（原始日志 `docs/verify-r2-06-e2e.txt`）：

| 环节 | 断言结果 |
|---|---|
| 预览 | 50 行：45 有效 / 5 缺测 / 1 条仅照片（内容不足）/ 0 冲突；落盘图片 4 张 |
| 导入 | 新增 50 条；重复导入同一包 → 新增 0、识别 50 条重复 |
| 三态不混 | 有效 44 + 内容不足 1 + 缺测 5 = 50；缺测记录在 `mistakes` 中**零行** |
| 批次配置 | 应作答 10、作答 9（一名学生五题全缺测）、未提交 0；名单再加一名零作答学生 → 应作答 11 |
| 批量核验 | 队列 50 条、失败 0；整批重跑后已确认判断一字不变 |
| 错因 | 确认 18 条 → 统计「已确认错题数」=18 = 库内 `decided` 行数 = `mistakes` 行数 |
| 评分 | 6 名学生全题确认 → 覆盖率 60%、平均分 500（每生 5 题 ×100）；只评一题的学生不计入平均分 |
| 撤回联动 | 撤回 1 条错因 → 18→17，且该条核验与评分仍在（R2-INV-03） |
| 演示隔离 | 插入合成演示作答 → 18 张指标卡逐字段不变 |
| 报告 | 预览含班级名与统计口径；渲染 3 页 PDF；导出文件可回读中文；个人报告不含他人 |
| 资源推荐 | 完全匹配的「待审核」资源仍退回「人工补充」 |
| 重启 | 18 张卡片逐字段相等；导出历史可读 |
| 备份/恢复 | 清单里十个 R2 表条数齐全；换机恢复后导出历史一条不少且 `class_id` 已重映射 |

## 七、集成期发现并修掉的问题（12 处，都是"全绿也照样错"的类型）

| # | 问题 | 后果 | 处理 |
|---|---|---|---|
| 1 | 契约 §10「评分覆盖率」分母写成应作答人数 | 有「只含不参与评分题目」的学生时覆盖率被算低 | 改为应参与评分学生数 |
| 2 | 契约 §10「作业总分」分子写成 Σ满分 | 拿满分之和冒充得分之和 | 改为逐生有效确认得分之和，满分量单列 `batch_full_score` |
| 3 | 契约 §10「重复错误」只统计知识点 | 同一错因重复的学生被算成 0 | 拆 `knowledge_pairs` + `cause_pairs` |
| 4 | 契约 §10「作答人数」写成有任一记录 | 五题全缺测的学生被算作答 | 加「非缺测」限定，验收集应为 9 不是 10 |
| 5 | 契约 §10「有效作答数」未写非缺测 | 恰好没暴露，属侥幸 | 定义补「非缺测」 |
| 6 | 契约 §10「班级人数」写成在册学生数 | 学生筛选后分母不跟统计范围走 | 改为「当前统计范围内」，并写死两条可断言约束 |
| 7 | 契约「班级共性问题」按频次主排 | 把"个别学生反复错"当"全班共性" | 改按涉及学生人数主排、频次辅助 |
| 8 | 契约「个人重点问题」未指向原版加权 | 看板与个人学情给出两种排序 | 明确复用 `tutor.py` 3/2/1 近期加权，并用断言逐字核对常量 |
| 9 | `scoring_students` 传参边界未写清 | 只传已作答行会让未提交学生漏出分母 | docstring 补全格子语义 + 双断言（10 vs 9） |
| 10 | 评分标准版本是**批次级** | 改一道题的标准会让整批成绩作废 | 下沉到题级 `rubrics[题号]`，按题失效，含变异体自证 |
| 11 | 导出历史写侧车 JSON | 备份→换机恢复后历史整批消失 | 入库 `r2_report_exports`，恢复时按题重映射搬移 |
| 12 | 备份包未剔除他人导出历史 | 一位老师的备份里混进另一位老师的导出记录 | `create_backup` 清 `user_id<>?` 的行 |

另有一处**接线期静默降级**：`ui_import_zip` 按方法名探测 service，我的方法名与探测名不一致会让它
静默退回直连模块、绕过归属闸门（按钮照用，看不出异常）。已改名对齐并加两条断言
（探测名存在 + spy 证明窗口调用经过 `owned_class_row`）。

## 八、未解决问题与边界（如实登记）

1. **首批 52 条真实教学资源全部「待审核」**：按派单 §7.2，人工双审核（数学正确性 + 教学适切性，
   两位老师分别签）未完成前不进正式推荐。软件功能用合成测试资源验收通过，**内容上线需人工审核**。
2. **手写 OCR 未做**：派单明确本轮不新增；仅照片作答存为「内容不足」等老师补录。
3. **打包版未做代码签名**：Windows 首次运行可能提示未知发布者，属预期。
4. **网页端未加 R2 入口**：本轮仅桌面端；R2 的服务层未走 api 路由（桌面端进程内直调），
   将来若要让网页端复用，需要补 `ROUTES` 与归属校验（判据可直接复用 `owned_class`）。
5. **`r2_report_exports.path` 是导出当时的本机路径**：换机器后该路径不存在属正常，界面上只作历史记录展示。
